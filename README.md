# SkillSwap

A web-based peer-to-peer skill exchange platform. Users pick skills they can teach and skills they want to learn, then get matched with people who fit both sides.

**Live demo:** https://YOUR-USERNAME.github.io/skillswap/

## Features
- Skill matching: pick "I can teach" and "I want to learn" keys, press Swap
- Mutual-swap detection (each person can teach the other)
- Add custom skills
- Browse and search people and skills
- Connect: in-page chat, session booking, 1-5 star ratings

## Tech
Plain HTML, CSS and JavaScript in one file (`index.html`). No build step, no dependencies. Fonts load from Google Fonts.

## Run locally
Open `index.html` in a browser.
